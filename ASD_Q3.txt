Step 1: Start Docker Desktop
1. Press the Windows key.
2. Search for Docker Desktop.
3. Open it.
4. Wait until Docker Desktop finishes starting and shows that the engine is running.
Keep Docker Desktop open.
Step 2: Check whether Docker is running
Return to PowerShell and execute:
docker info


If Docker is working, the output should include server information such as the number of containers and images, and the Storage Driver.

Then run:
docker ps


If it works without the connection error, proceed to Step 3.
Step 3: Navigate to your project folder
Your current location is:
C:\College\ASD


First, check its contents:
dir


You should see:
Dockerfile
index.html


If these files are inside a separate docker-web-app folder, navigate into it:
cd C:\College\ASD\docker-web-app


Important: Run the build command from the folder containing your Dockerfile.
Step 4: Build the image
Once Docker is running and you are in the correct folder:
docker build -t my-web-app .


Step 5: Run the container
docker run -d -p 8080:80 --name my-web-container my-web-app


Verify it:
docker ps


Step 6: Test in your browser
Open:

http://localhost:8080

Your sample web page should appear.
